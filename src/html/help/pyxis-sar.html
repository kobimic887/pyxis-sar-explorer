SAR Quick Start

Pyxis SAR Explorer is a modified version of DataWarrior. Everything described in the other chapters of this manual works as in DataWarrior. This chapter covers what Pyxis added: the SAR menu and two additions to tables and views.

You need a table with a chemical structure column and, for most steps, one column of measured numbers such as an IC50. No file at hand? Choose SAR -> Open Example Project. It opens 288 COX-2 inhibitors with published IC50 values from ChEMBL; the example names its source in its Explanation view.


1. One step to an overview

Choose SAR -> SAR Overview..., select the structure column and the value column (COX-2 IC50 (nM) in the example) and press OK. The program then

  • adds a Scaffold column and the substituent columns R1, R2, ... to the table,
  • opens the scaffold tree, and
  • opens a second document, Substituent Swaps, if at least one pair of molecules differs in exactly one substituent.

If your molecules have no ring in common, tick Use my own core instead of ring scaffolds and draw the common part with Draw Core.... Substituents are then defined around that core.


2. The scaffold tree

Every ring system found in the molecules is one entry. A scaffold that is contained in a larger one appears as its parent. Each entry shows the number of molecules and, once a value column is chosen under Statistics at the bottom of the window, the mean and median of that value and a colour from blue (low) to red (high).

  • Double click a scaffold to select its molecules in the table and in all views.
  • Tick Only molecules with exactly this scaffold to leave out molecules of larger scaffolds that merely contain it.
  • Right click a scaffold for Edit Scaffold... (adds a scaffold of your own, matched as a substructure) and Re-orient Family (draws all molecules of the family in the same orientation).
  • Report To MS Word writes the tree with pictures and statistics; Tree As New Table turns it into a document of its own.

The tree's settings and your own scaffolds are saved with the project.


3. Which exchange matters

The Substituent Swaps document has one row per exchange of one substituent by another, counted over all scaffolds: how many pairs of molecules show it, the mean and median change of the value, the fold change, and how often the value went up or down. Sort it by Pairs With Values to see the best supported exchanges first. Selecting a row selects the molecules behind it in the original table.

SAR -> Analyse Substituent Pairs... lists the individual pairs. Its second mode, same substituents, different scaffold, lists scaffold hops.


4. The R-group grid

SAR -> Create R-Group Grid... lays out one scaffold's molecules with one substituent position as rows and another as columns. Every cell shows the combined value (median, mean, minimum, maximum or count) and the number of molecules; combinations nobody made are marked Empty. Click a cell to select its molecules. The grid can be saved as a picture or turned into a table.


5. In the table and the views

  • Lock columns: right click a column header and choose Lock Columns Up To '...'. These columns stay in view while you scroll to the right. Unlock Columns ends it.
  • Let one view filter another: right click a 2D or 3D view and choose Show Only Rows Selected In Other Views. Whatever you select elsewhere, for instance with a lasso in a second plot, decides what this view shows.
  • Table to Word: SAR -> Export Visible Table to MS Word... writes the visible rows and columns with structure pictures.

Locked columns and the view restriction are saved with the project.


6. Repeating an analysis

All steps of the SAR menu can be recorded and replayed as macros, see Using Macros. Their task names are SAR Overview, Build Scaffold Tree, Create R-Group Table, Create R-Group Grid, Analyse Substituent Pairs, Summarise Substituent Swaps, Export Visible Table To MS Word and Open SAR Example.


What to keep in mind

  • Scaffolds are ring systems with their linkers after removing all side chains; stereo information is not part of a scaffold.
  • Substituent swaps compare molecules that share a scaffold and differ at one position only. A mean change over few pairs is weak evidence; look at the pair count.
  • Derived documents (swaps, pairs, R-group tables, grids) are snapshots. They stay linked to the original table until either window is closed; later changes of the data need a new run.
